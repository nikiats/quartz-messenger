# System design

## Соединение с пользователем

**Сервер соединений: управление постоянными соединениями с активными клиентами**

- удержание активных дуплексных соединений с клиентами, пользователи которых находятся онлайн
- доставка данных пользователю и на сервер с минимальными задержками

**Сервер сессий: отслеживание состояний подключенных к серверу соединений клиентов**

- отслеживание соединений пользователя с сервером соединений
- пересылка сообщений сервер соединений

**БД для хранения информации о подключениях**

- кратковременное хранение информации об активном соединении между клиентом и сервером соединений
- быстрый доступ к информации о том, с каким сервером соединений связан клиент

Выбрана база данных типа *ключ-значение* в силу необходимости высокой скорости и примитивной структуры хранимых данных.

## Бизнес-логика

**Сервер сообщений: обработка сообщений, бизнес-логика**

- упорядочивание сообщений
- управление правами пользователей
- сохранение сообщения
- другие задачи, связанные с бизнес-логикой

**БД для хранения сообщений**

- долговременное хранение сообщений
- быстрый доступ к сообщениям

Выбрана *документоориентированная* база данных в силу отсутствия строгих ограничений на содержимое сообщений и необходимость работы с большими данными.

**БД для хранения учетных данных (пользователей, чатов)**

- долговременное хранение данных пользователей
- долговременное хранение единиц бизнес-логики (группы, блокировки)

Выбрана *реляционная* база данных в силу наличия ограничений на данные, и частые связи между хранимыми объектами.
