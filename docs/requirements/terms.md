# Принятые бизнес-правила

## Пользователи

**Пользователь** - лицо, применяющее мессенджер для коммуникации с другими пользователями.
Чтобы стать пользователем, необходимо пройти регистрацию по логину и паролю.

Пользовательский аккаунт может быть деактивирован.
Условия деактивации не регламентированы и остаются на усмотрение администрации мессенджера.

## Групповые чаты

**Групповой чат** - чат, доступ к которому имеет один или более пользователей, именуемых участниками.
Участник может быть *администратором*.
В рамках одного чата <u>должен быть ровно один администратор</u>.
Администратором создаваемого чата становится его создатель.

Администратор обладает следующими полномочиями:
- добавление участников в групповой чат;
- удаление участников из группового чата;
- удаление чата;
- передача привилегий администратора любому другому участнику чата (нет в MVP);
- переименование чата (нет в MVP).

Каждый пользователь, включая администратора, может покинуть групповой чат по собственной инициативе. 
При выходе администратора, новый администратор выбирается псевдослучайным образом.

При выходе последнего оставшегося пользователя, являющегося администратором, чат считается удаленным.


## Личные чаты

**Личный чат** - чат ровно двух пользователей.

Между двумя пользователями существует не более одного личного чата: повторное
обращение к уже существующему диалогу не создает новый.

Состав участников личного чата неизменен: добавить или удалить участника нельзя, покинуть чат невозможно.
Вместо этого у любого из участников личного чата есть возможность удалить весь чат для обоих участников.
Администратора в личном чате нет, права участников одинаковы.

При удалении личного чата для возобновления переписки необходимо создание нового, что допускается.
