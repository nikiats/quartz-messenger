# Средства реализации

## Серверные компоненты

Для реализации всех серверных компонентов выбран язык программирования `Golang`.
Обоснование выбора:

- высокая производительность
- высокая степень контроля на этапе компиляции
- низкое потребление оперативной памяти
- наличие горутин для множества одновременных соединений

## Базы данных

**Реляционная**: `PostgreSQL`, так как есть поддержка UUID и JSONB по умолчанию.

**Документоориентированная**: `MongoDB`, так как подходит для хранения сообщений в виде документов с произвольной JSON структурой.

**Ключ-значение**: `Redis`, так как есть возможность хранения данных в памяти для ускорения доступа.
