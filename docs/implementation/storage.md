# Решения по хранению данных

## Участники чатов

Участники любого чата, включая личный, хранятся в `chat_members`.

Пара пользователей `user_a` и `user_b` в `chats` используется для формирования ключа личного чата и позволяет защититься от создания нескольких чатов для одинаковых собеседников. Эти поля заполняются только для личных чатов.

Роль участника определяется по тому, записан ли он как администратор чата. Если не записан, значит это обычный пользователь.

## Удаление чата

После удаления чата с базе данных чат отмечается, как удаленный.
Поле `admin` хранит ID последнего администратора чата.
Таблицы `chat_members` и `messages` не претерпевают изменений при удалении чата.

## Нумерация сообщений

Порядковый номер последнего сообщения хранится в строке чата.
В одной транзакции осуществляется инкремент номера под блокировкой и вставка сообщения с данным номером.
