# Реализация MVP

## Упрощения для MVP

**Б1** и **Б2** объединены в единую сущность `PostgreSQL`, разделены на уровне таблиц.<br>
**С1** и **С2** объединены в единый сервис **С12** в силу наличия единственного шлюза.

**Д1** упразднен: сервис мессенджера **С3** сообщает об инвалидации сессий шлюзу **С12** напрямую.<br>
**Б3** упразднен: шлюз **С12** ведет учет соединений самостоятельно в памяти процесса.<br>
**Б4** упразднен: сервис мессенджера хранит инвалидированные сессии в памяти процесса.

## Итоговый начальный стек

**I. Шлюз соединений:** поддержка соединений с клиентами и доставка сообщений.<br>
**II. Сервис мессенджера:** вся логика обработки сообщений, управление аккаунтами, отозванные сессии.<br>
**III. PostgreSQL:** долговременное хранение сообщений, профилей, сессий, прочих учетных данных.
