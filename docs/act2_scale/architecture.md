# Архитектура

Задача состоит в том, чтобы сделать мессенджер _горизонтально масштабируемым_.

Для этого необходимо перейти на другие системы хранения данных и переработать сервисы шлюза и мессенджера под работу в числе нескольких копий.

## Компоненты

**Балансировщик нагрузки**

**N инстансов сервиса мессенджера**
**M инстансов сервиса шлюза**
**K хостов хранилища сообщений**
**L хостов хранилища пользователей**
**P хостов in-memory хранилища**
**Q хостов pub/sub системы**
**R хостов поискового сервиса**

## Детализация

### Балансировщик нагрузки

**Задачи:** проксирование соединений пользователей с инстансами мессенджера и шлюзами соединений.
