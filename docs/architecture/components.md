# System design

## Соединение с пользователем

**Шлюз соединений: поддержка соединений с активными клиентами**

- удержание дуплексных соединений с клиентами, пользователи которых находятся онлайн
- доставка сообщений с минимальными задержками

**Менеджер соединений: учет соединений пользователей со шлюзом**

- систематизация соединений со шлюзами
- определение шлюза, на котором подключен клиент

**БД для хранения информации о соединениях**

- хранение информации об активном соединении между клиентом и шлюзом
- быстрый доступ к информации о том, с каким шлюзом связан клиент

## Бизнес-логика

**Сервис мессенджера**

- управление сообщениями, включая пересылку на шлюзы
- управление пользовательскими аккаунтами и настройками
- управление группами
- управление сессиями пользователей и их валидация

**БД для хранения активных сессий**

- хранение информации об активных сессиях пользователей
- удаление сессии по TTL или инвалидация при определенных событиях
- быстрая проверка валидности сессии

**БД для хранения сообщений**

- долговременное хранение сообщений
- быстрая запись сообщений
- поиск сообщений по строке

**БД для хранения учетных данных (пользователей, групп)**

- хранение данных пользователей, включая настройки профиля
- хранение данных о группах
- дополнительные единицы бизнес-логики, например блокировки при внедрении
