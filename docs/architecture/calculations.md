# Расчет нагрузки

Приведены грубые расчеты на основе общедоступных данных.

## Бизнес-требования

Пусть заданы следующие условия:

Среднее число активных пользователей мессенджером в день `DAU = 1 млн`.
Число отправленных одним активным пользователем сообщений в день в среднем `MsgAverage = 100`.
Пиковый множитель для моментов с повышенной интенсивностью отправки сообщений `PM = 10`.

Тогда в секунду отправляется в среднем `MPS = DAU * MsgAverage / 86400`, а максимально
`MaxMPS = MPS * PM`.

> MPS = 1 158 сообщений/с<br>
> MaxMPS = 11 580 сообщений/с

## Расчет требуемых ресурсов

**Дисковое пространство**

Пусть средняя длина сообщения `MsgLen = 100 символов`.

В большинстве сообщений в русскоязычных мессенджерах используют кириллические символы, либо
символы ASCII. Примем объем одного символа равным `2 байтам` (кодировка UTF-8).

Тогда вес одного сообщения оценим как `I = 100 * 2 байта = 200 байт`.

Объем сообщений, сохраняемых за день `IDay = 1158 * 86400 * I = 18.64 ГБ`

Для одного года следует выделить `IYear = IDay * 365 = 6.65 ТБ` для хранения данных.

**Оперативная память**

RAM используется по большей части для работы in-memory key-value БД.
Такая БД используется для хранения информации о подключениях пользователей.

Допустим, необходимо управлять числом соединений, равным `DAU`.
Данные об одном соединении - приблизительно `5 КБ` с учетом накладных расходов СУБД.

Тогда `RAM = 5 КБ * DAU = 5 ГБ`. 
Для наличия большого запаса можно принять требование равным `12-16 ГБ`.

**Процессорное время**

Пусть одно ядро обрабатывает `CoreRPS = 1000 запросов/c`.
Будем считать, что один запрос от пользователя приводит к каскаду запросов к внутренним сервисам,
коэффициент пусть будет `CM = 10`. 
В этом же коэффициенте заложены и другие запросы пользователя, не включающие в себя отправку сообщений.

Тогда `Cores = MaxMPS * CM / CoreRPS = 116 ядер`.
Будет необходимо развернуть сервисы на нескольких хостах для равномерной нагрузки.

# Итог

На один год работы требуются следующие ресурсы:

> 10 ТБ дисковое пространство<br>
> 16 ГБ оперативной памяти<br>
> 120 ядер процессора

Значения завышены, чтобы был запас по ресурсам.
