# Quaztz

## Назначение проекта

Обмен короткими текстовыми сообщениями.
В данный момент стадия развития - MVP.

Исходная постановка задачи: [TASK.md](./TASK.md)

## Документация

Документация разделена на три уровня: **требования** описывают, что должна делать система,
**проектирование** описывает целевую архитектуру, **реализация** описывает, как она воплощена в MVP.

### 1. Требования

| Документ | Содержание |

| [Расчет нагрузки](./docs/requirements/calculations.md) | оценка нагрузки и требуемых ресурсов |
