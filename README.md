# Quartz Messenger

## Назначение проекта

Многофункциональный сервис для обеспечения коммуникации между людьми в реальном времени.

Постановка задачи: [TASK.md](./TASK.md)

## План развития

- [x] MVP: реализация минимальных требований ТЗ;
- [ ] Scale: добавление возможности горизонтального масштабирования, оптимизация под максимальную пропускную способность;
- [ ] Features: добавление функционала, указанного в расширенных требованиях ТЗ (кроме суммаризатора LLM);
- [ ] Security: суммаризатор LLM с базовой модерацией на его основе.
- [ ] Cleanup: исправления документации, подготовка к сдаче.
